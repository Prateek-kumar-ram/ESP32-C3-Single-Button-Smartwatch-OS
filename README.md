# ESP32-C3-Single-Button-Smartwatch-OS
An open-source, ultra-low-power smartwatch OS for the ESP32-C3. Features a single-button interface, AOD, and embedded apps including a Dino game, Coin Toss, Stopwatch, and Secure Text Vault. Includes a standalone Wi-Fi portal for syncing time, uploading text, and customizing settings. Perfect for DIY makers and minimalist wearable projects!
